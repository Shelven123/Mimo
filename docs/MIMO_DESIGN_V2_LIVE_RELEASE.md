## Verification and limits

Automated regression, inline-script identity/syntax, unique controller IDs and six-page navigation consistency are checked. Preview checks cover its independent draft/call simulation. After merge, exact runtime bytes and browser public-page appearance are checked separately. These checks do not constitute physical iPhone keyboard/call/media or signed-in customer-flow acceptance. The approved prototype is User Verified visually; the production adaptation requires its own feedback. No pixel-identical or multi-device acceptance claim.

Existing Home internal scrolling, chat viewport handling and dedicated Reels comment geometry remain. Prototype-only device chrome is removed through CSS; formal pages never contained it. Call labels do not imply physical speaker/earpiece routing, which remains browser/device controlled.

# Plaza comment/share/media experience

Implemented: mobile bottom sheets with native modal focus/backdrop, scrollable comment area, fixed input/emoji row, reply context, avatars, true comment like counts/state and author-liked indicators. One-level replies load on demand, paginate and delete with their root. Failed mutations retain drafts/retry UUIDs; late responses after close/account changes are suppressed. Replies expand again after a mutation refresh; they are not automatically kept expanded. No translation service or animated stickers implemented.

Sharing (the owner's correction: reference 2 is SHARE, not Repost): round platform icons in a horizontal row, real recent Mimo conversation avatars, single-recipient selection and explicit Send. Invoker RPC sends a canonical post link into an existing owned conversation; retry IDs prevent duplicates, block/privacy checks retained. No outbound messages were sent for testing. External Facebook/Telegram/X/WhatsApp targets retained; Instagram/TikTok copy link or use native sharing where offered. This does not directly publish to those services. Existing Repost marks unchanged.

Media: separate All / Photos / Reels category icons. Photos display a three-column grid; opening a tile shows the existing full card in a detail sheet. Reels filter actual video posts and render inline controls, cover images where supplied, no autoplay, one playing video at a time, pause on hidden page/close. Category filtering occurs server-side before pagination and combines with Discover/Saved/Reposts. Host composer optionally accepts up to six direct hosted HTTPS image URLs and one hosted video URL/cover; data is checked by server guards, media identity immutable. No roles or seed media changed. This is link-based publishing, not local file uploads, video transcoding, duration validation or an Instagram-scale Reels recommender. A valid HTTPS link does not guarantee a decodable or available media file.

Verified locally: 148 PostgreSQL/JSDOM/Canvas checks, JS/inline syntax and whitespace. New cases cover media role/URL/immutability/filter pagination, reply-parent same-post/root constraints and cascades, blocked parent/likes, share foreign-conversation/block/retry controls, modal/emoji/thread behavior, late-query cleanup, real contact selection and video non-autoplay. JSDOM is not a rendered browser or phone test. Live migration, comment-likes RLS/three policies, video/reply columns, six invoker functions/anonymous denial and no-UID empty feed/comments/likes verified. Advisors unchanged.

Not Verified: physical-phone layout/keyboard/native dialog gestures, actual hosted video decoding/network playback, production transactional new likes/replies/media/chat sharing and concurrency, actual cross-app sharing. Existing reported image uploads/moderation/quotas and financial gifts remain incomplete as previously documented; no gift or wallet behavior changed. No Beauty/call edits.
